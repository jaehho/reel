# reel

Tauri app (`src-tauri`, UI in `ui/`) over a headlessly tested engine (`crates/reel-core`). `README.md` covers install, use, and how it works; `PRODUCT.md` is the product and design brief for UI work.

- Open work lives in GitHub issues (`gh issue list`).
- Design history and the reasons behind it: `gh issue list --label decision --state all`. Past bugs and traps with their evidence: `gh issue list --label gotcha --state all`. Search these before changing behavior they cover; reopen a gotcha on recurrence.
- Record a new decision or gotcha as an issue with that label, not a log file.
